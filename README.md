# Breckenridge snow forecast

A live, Breckenridge-only snow forecast that pulls the latest model runs (HRRR, National Blend, ECMWF, GFS, ICON, GEM, and the GFS/ECMWF ensembles) in the browser, corrected against ten winters of snow measured in Breckenridge.

Open `index.html` (published with GitHub Pages). `tools/` holds the monthly recalibration scripts.
